# Event Crowd Management System

A MERN-based Event Crowd Management System for managing events, user registrations, ticket booking, QR-based check-in, crowd monitoring, and event analytics.

## Features

- User Registration and Login
- Event Registration
- Ticket Booking
- QR-based Check-in
- User Dashboard
- Admin Dashboard
- Crowd Monitoring
- Event Analytics
- Reports
- My Tickets

## Technology Stack

### Frontend
- React.js
- Vite
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
